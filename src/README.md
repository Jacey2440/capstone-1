# Capstone 1 - Accounting ledger
# Overview:
The Banking Ledger Application helps users record and manage their financial transactions. It allows you to add deposits, make payments, and view a ledger of all transactions saved to a CSV file. Each entry includes the date, time, description, vendor, and amount, providing an organized way to track income and expenses.

# Features :
===Main menu===

The user can:

 D) Add Deposits

 P)Make Payments (Debits)

 L)View their Ledger to see all transactions

X) Exit


All transactions are saved into a CSV file named transactions.csv

===Ledger menu===
 
A) Display all

D) Deposit only

P) Payments only

R) Reports
